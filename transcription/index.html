드럼 채보 모델 정리

음원에서 뽑은 드럼 소리를 듣고 "몇 초에 어느 패드를 쳤는지" 적어 주는 모델을 골랐고, 부족한 부분을 추가 학습으로 보완했음. 자세한 측정 과정은 모델 선정 과정 페이지에 있고, 이 페이지는 핵심만 쉽게 정리한 것임.

1. 후보 모델군

공개된 드럼 채보 모델 8개를 찾아 6개를 실제로 돌려 봤음.

채보 모델은 드럼 소리를 0.01초 단위로 잘라 보면서 "지금 킥을 쳤나, 스네어를 쳤나"를 확률로 냄. 확률이 높게 튀는 순간이 타격 하나가 됨. 모델마다 구분하는 드럼 종류 수가 달라서, 우리 게임 패드 8개(킥·스네어·하이햇·스몰탐·미드탐·플로어탐·크래시·라이드)를 그대로 채울 수 있는지가 가장 큰 차이였음.

ADTOF + 드럼 킷 분리가 뭔가

ADTOF는 실제 밴드 녹음에서 점수가 가장 좋지만 킥·스네어·하이햇·탐·심벌 5가지만 구분함. 그래서 드럼 소리를 킥·스네어·탐·하이햇·라이드·크래시 6개 소리로 한 번 더 나누는 모델(드럼 킷 분리)을 같이 돌림. ADTOF가 "탐"이라고 적은 타격은 탐 소리의 음높이로 스몰·미드·플로어를 정하고, "심벌"이라고 적은 타격은 크래시·라이드 소리 중 큰 쪽으로 정함.

2. 벤치마크 결과

8패드 기준 점수에서 ADTOF + 드럼 킷 분리가 1등이었음. 다만 탐 세 개는 거의 못 나눴음.

채점은 모델이 적은 노트와 정답 노트를 짝지어서 함. 시각 차이가 앞뒤 0.05초 안이고 패드가 같으면 맞힌 것임. 점수는 F1로 냄. F1은 "모델이 적은 것 중 맞은 비율"과 "정답 중 잡아낸 비율"을 하나로 합친 값이고 1이 만점임.

8패드 F1, 시각 허용 ±0.05초. 앞 두 열은 정답 드럼 녹음을 바로 넣은 값, 마지막 열은 서비스처럼 노래 전체에서 드럼을 뽑아 넣은 값. 전자 드럼은 GMD, 실제 밴드 녹음은 MDB Drums 데이터셋.

  • 노래에서 드럼을 뽑아 넣어도 점수가 거의 그대로임. 드럼을 안 뽑고 노래 전체를 넣으면 0.08 떨어짐
  • 맞힌 노트의 92% 이상이 정답과 0.025초 안에 있음. 허용 폭을 0.1초로 넓혀도 점수가 0.002밖에 안 올라서, 박자 위치는 믿어도 됨
  • 약점은 탐임. 실제 밴드 녹음에서 탐이 거의 다 플로어탐으로 적혔음. 탐을 나누는 음높이 기준을 전자 드럼으로 정했기 때문이었음
  • 그래서 곡마다 탐 음높이를 따로 재서 상대적으로 나누는 규칙으로 바꿨음. 실제 밴드 녹음 탐 3종 F1이 0.21에서 0.67로 올랐음

3. 추가 학습

탐과 하이햇 페달을 보완하려고 ADTOF를 우리 데이터로 다시 학습시켰음.

왜 했나

  • 하이햇 페달: 원래 ADTOF는 발로 밟는 하이햇을 아예 안 냄
  • 처음 보는 드럼 세트의 탐: 실제 드러머 3명이 친 ENST 데이터에서 탐 3종 F1이 0.30에 그쳤음. 특히 킥을 높게 조율한 드러머 1의 세트에서 킥을 플로어탐으로 적는 일이 많았음
  • 약하게 친 스네어: 놓친 스네어의 대부분이 아주 약하게 친 장식 타격이었음

무엇으로 학습했나

  • 세 모델 모두 같은 구조이고 크기도 같음. 학습 데이터만 다름
  • 실제 녹음 추가 모델은 공정하게 재려고 3번 따로 학습했음. 매번 ENST 드러머 1명과 MDB 곡 1/3을 학습에서 빼고, 뺀 곡으로만 채점함. 세 번의 결과를 합치면 모든 곡을 "학습 때 못 들은 곡"으로 채점한 것이 됨
  • 학습 1번에 GPU 서버에서 약 1시간 걸림

작성 중

서비스에 넣을 버전은 실제 녹음 전체로 다시 학습하는 중임. 끝나면 결과와 드럼 분리 입력 기준 비교를 여기에 추가함.

5. 한계

  • 처음 보는 드럼 세트의 탐 이름: 탐을 쳤다는 건 잡아도 스몰·미드·플로어 중 어느 탐인지 자주 틀림. 다른 공개 모델과 상용 서비스도 같은 문제를 가지고 있음
  • 크래시와 라이드 구분: 심벌을 친 건 잘 잡지만 어느 심벌인지는 실제 녹음에서 0.3~0.6 정도로 낮음
  • 패드에 없는 악기: 탬버린·카우벨 같은 소리를 비슷한 패드로 적을 수 있음
  • 평가 데이터가 적음: 실제 녹음 탐 정답이 MDB 90타, ENST 694타뿐이라 탐 점수는 곡 몇 개에 크게 흔들림
  • 위 표는 대부분 깨끗한 드럼 녹음 입력 기준: 서비스처럼 노래에서 드럼을 뽑아 넣은 값은 학습 모델에서 아직 재지 않았음
  • 라이선스: ADTOF 가중치는 비상업 조건이고, ENST는 학생 학업용으로만 학습을 허락받았음

6. 최종 및 추후 계획

작성 중

실제 녹음 전체 학습과 드럼 분리 입력 비교가 끝나면 최종 모델과 다음 계획을 채움.

용어 정리

F1모델이 적은 노트 중 맞은 비율(정밀도)과 정답 중 잡아낸 비율(재현율)을 하나로 합친 점수. 0~1, 1이 만점
8패드 · 9패드게임 패드 8개 기준으로 매긴 점수. 9패드는 여기에 하이햇 페달을 더한 것
탐 3종 F1스몰탐·미드탐·플로어탐 이름까지 맞아야 맞힌 것으로 치는 점수
드럼 분리 입력노래 전체에서 음원 분리 모델로 드럼 소리만 뽑아 채보 모델에 넣는 것. 서비스가 쓰는 방식
파인튜닝이미 학습된 모델을 우리 데이터로 이어서 더 학습하는 것
BPM1분에 박이 몇 번인지. 110 BPM이면 한 박이 약 0.55초
