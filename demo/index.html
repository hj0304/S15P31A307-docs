서비스에 들어가는 분리 모델 BS Roformer SW로 요즘 곡 세 곡을 분리한 결과. 사용자가 곡을 올리면 이 과정을 거쳐 드럼은 채보 모델로, 드럼리스 MR은 플레이 화면 반주로 감.

들을 때 보면 좋은 점
  • 드럼리스 MR이 원곡보다 작거나 먹먹하게 들리는지. 세 곡 모두 MR이 원곡보다 0.6~1.7dB 작고, 5kHz 위 고음 에너지가 원곡의 절반 아래로 줄었음. 하이햇·심벌이 빠진 몫이 크지만 다른 악기 고음이 같이 빠졌는지도 들어 보면 좋음
  • 분리한 드럼에 보컬·신스·베이스가 섞여 들리는지
  • 드럼리스 MR에 킥·스네어·심벌이 남아 있는지
  • 혜성은 분리한 드럼이 먹먹하게 들림. 스네어가 있는 150Hz~5kHz 소리가 드럼 쪽으로 거의 안 왔음
  • 분석 결과는 음원 분리 실제 곡 평가 8장에 있음
  • MR이 작고 먹먹하게 들리던 문제를 고친 과정과 비교 파일은 아래 드럼리스 MR 개선 실험에 있음

드럼리스 MR 개선 실험

S15P31A307-165

2026-10-31. 위 MR이 원곡보다 작고 먹먹하게 들리는 문제를 고친 과정. 숫자는 이 페이지 mp3로 잰 원곡 대비 음량 차이(LUFS)임.

무엇을 바꿨나
  • 원곡은 크게 마스터링돼 있어서 드럼을 빼면 MR 일부가 파일에 담을 수 있는 최대 크기를 넘음. 지금 서비스는 넘는 부분을 잘라 저장해서 그 순간 소리가 찌그러짐
  • 곡 전체 볼륨을 낮춰 잘림을 막으면 MR이 원곡보다 3.8~6.2dB 작아짐
  • 채택: 리미터. 최대 크기를 넘으려는 순간에만 볼륨을 낮추고 100ms에 걸쳐 되돌림. 원곡과 차이 1.2~3.1dB, 잘림 없음. 5ms 만에 되돌리면 킥·베이스가 울렁일 수 있어 100ms로 함
먹먹함은 왜 남나
  • 드럼이 칠 때 반주 일부가 분리한 드럼 쪽으로 같이 빠짐. 사람이 만든 공식 드럼리스 곡과 비교하면 드럼이 큰 순간에 우리 MR이 1.7dB 작고, 드럼이 조용한 순간은 차이가 없음
  • 원곡보다 고음이 적은 건 드럼이 빠지면 원래 생기는 차이임. 악기별 정답이 있는 MUSDB18 50곡에서도 정답 MR이 원곡보다 5kHz 위가 3.7dB 작음
  • 드럼을 90·95%만 빼면 덜 먹먹하지만 드럼이 남아 쓰지 않음. 8kHz 위 +2dB와 원곡 기준 마스터링은 원곡처럼 밝아지지만, 공식 드럼리스보다 고음이 4dB쯤 밝아지고 남은 소리도 같이 커져 쓰지 않음
  • 분리 모델·설정 후보 7개를 ENST 64곡·MUSDB18 50곡에서 비교했지만 지금 설정보다 나은 것이 없었음. 곡마다 아래 접힌 목록에서 들을 수 있음
